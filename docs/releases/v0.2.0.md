# DepReach 0.2.0

This release improves explainable Python reachability and adds an npm SCA
preview with verified dependency sources and JavaScript/TypeScript syntax facts.
Analysis does not require an AI service.

## Python analysis

- Resolve qualified symbols, scoped imports, intermediate dependency sources,
  simple inheritance, properties and supported callback flows.
- Map fix patches against exact-version sources, retaining commit provenance,
  mapping evidence and the distinction between patch candidates and reviewed
  vulnerability targets.
- Keep missing sources and unsupported dynamic behavior explicit. A possible
  static path is triage evidence, not proof of exploitability.
- Reuse captured source bytes and call graphs across findings; invalidate cached
  results when source or analysis inputs change.
- Export consistent evidence and limitations in JSON, HTML and SARIF.

## npm preview

- Read npm package-lock/shrinkwrap v2/v3 with nested installation identities,
  aliases, workspaces and runtime/dev/optional scope.
- Verify supported registry source archives against lockfile integrity and
  package identity. Support bundled and local workspace source provenance.
- Extract JS/JSX/TS/TSX functions, imports and call expressions using the optional
  node extra. JS/TS call-path reachability is not yet implemented; those findings
  remain unsupported, not safe or unreachable.

## Migration from 0.1.x

- Reachability JSON now uses an explicit status and nullable is_reachable.
  Unknown and unsupported results must not be treated as false.
- CLI scan exit codes: 0 = no known vulnerabilities in the supplied inventory;
  1 = no modeled path for every finding; 2 = at least one possible path;
  3 = inconclusive with no positive path; 4 = scan/export failure.
  Argument syntax errors still use argparse exit code 2.
- Existing unscoped reachability cache records are ignored.
- VDB requires >=6.6.1,<7. The node extra pins tree-sitter below 0.26 because of
  a reproduced Windows native crash in that version.

## Install

```sh
pip install --upgrade depreach==0.2.0
# Include the optional JS/TS parsers:
pip install --upgrade "depreach[node]==0.2.0"
```

## Validation and limitations

The preceding source commit passed 328 tests on Linux with Python 3.10, 3.11 and
3.12. The offline corpus contains 20 cases: seven positive, ten negative and
three expected indeterminate, with no incorrect conclusions in those cases.
These regression results are not an ecosystem-wide accuracy estimate.

See docs/NEXT_STEPS.md and docs/IMPLEMENTATION_STATUS.md for remaining work,
including broader Python framework coverage and full JS/TS reachability.
